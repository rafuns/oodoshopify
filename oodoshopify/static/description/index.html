Shopify Odoo Connector — Full Integration

Connect your Shopify store directly to Odoo. Sync orders, products, pricing, customers, inventory, and — uniquely — manage your Shopify theme settings without ever leaving Odoo. Full-featured, no artificial limitations, at a fraction of the cost of alternatives.

What makes this different: Built-in Shopify Theme Manager lets you switch themes, edit theme settings (colors, fonts, layout), and push CSS/JS assets directly from Odoo — a capability no other Odoo-Shopify connector offers.

Setup in 3 Steps

  1. Create a Shopify custom app in your Shopify admin (Settings → Apps → Develop apps)
  2. Connect Odoo to it — either paste the Admin API access token and click Test / Connect, or use Connect with OAuth for the full authorization flow
  3. Click Register Webhooks — all real-time event subscriptions (orders, products, customers, inventory, refunds, app-uninstall) are created in one click

Technical Details

  • Uses Shopify Admin API 2025-04 (GraphQL-first, REST for Theme API only)
  • OAuth 2.0 authentication — no manual token management
  • HMAC-signed webhook verification
  • Supports multiple Shopify stores (one instance per store)
  • Compatible with Odoo Online, Odoo.sh, and On-Premise

External Service — Shopify API

This module connects to Shopify, a third-party service. To function, it sends and receives data to/from the Shopify Admin API (https://<your-store>.myshopify.com/admin/api) using the credentials you provide for your own Shopify store.

  • Data sent to Shopify: products, prices, inventory, order fulfilment/tracking, customers, collections, discounts, metafields and theme settings that you choose to push.
  • Data received from Shopify: orders, products, customers, inventory levels, refunds, payouts, abandoned checkouts and related records.
  • Credentials: stored only in your Odoo database; never transmitted to the publisher.
  • You need: an active Shopify store and a Shopify custom/public app. Shopify is billed separately by Shopify; this module does not include a Shopify subscription.

No data is sent to the module publisher. All API calls go directly from your Odoo instance to your Shopify store. See Shopify's Privacy Policy and API Terms.
